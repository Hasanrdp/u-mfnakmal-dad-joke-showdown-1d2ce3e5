# Reheated Hits

One original dad joke for the
[make.fun Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5).

## The joke

> I told my wife I was going to start a band called The Leftovers. We only play reheated hits.

## How it works

`main.py` (Python 3.13, standard library only) writes that one joke — 92
characters, inside the 1–200 character gate — to `/output/entry.txt`. No
network, no randomness, no input: every run writes the exact same bytes.

## Why this joke

It was picked by pre-judging six original candidates with the competition's
own judge model (z-ai/glm-5.3-flash on OpenRouter) using the judge brief from
the kit, pairwise in both orders. "Reheated Hits" won the round-robin
(4 wins, 1 draw, mean game score 0.67): the pun lands on the first read, the
setup is a dad telling his wife at the table, and the punchline — reheated
hits — arrives as the last word.
